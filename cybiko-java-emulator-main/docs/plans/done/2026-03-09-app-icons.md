### Task 2: Decompressor — Implementation

**Files:**
- Create: `manager/src/main/java/com/github/daberkow/cybiko/manager/io/CybikoDecompressor.java`

**Step 1: Implement the decompressor**

The decompressor handles two blob types:
- `0x00`: uncompressed — return bytes after type byte
- `0x02`: compressed — bytes 1-4 = uncompressed size (BE), bytes 5+ = LZ77 bitstream

LZ77 bitstream (LSB-first bit reading):
- Flag bit 0: literal byte (read 8 bits)
- Flag bit 1: match (decode length via prefix tree, decode offset via prefix tree, copy from `pos - offset - length`)

See `docs/app-format.md` for the full length/offset decode trees.

```java
package com.github.daberkow.cybiko.manager.io;

/**
 * Decompresses Cybiko filer.exe compressed data blobs.
 * Type 0x00 = uncompressed, 0x02 = LZ77 bitstream.
 */
public final class CybikoDecompressor {

    public static byte[] decompress(byte[] blob) {
        if (blob.length == 0) throw new IllegalArgumentException("Empty blob");
        int type = blob[0] & 0xFF;
        if (type == 0x00) {
            // Uncompressed: raw data after type byte
            byte[] out = new byte[blob.length - 1];
            System.arraycopy(blob, 1, out, 0, out.length);
            return out;
        }
        if (type != 0x02) {
            throw new IllegalArgumentException("Unknown compression type: 0x" +
                Integer.toHexString(type));
        }
        // Compressed: bytes 1-4 = uncompressed size (big-endian)
        int uncompSize = ((blob[1] & 0xFF) << 24) | ((blob[2] & 0xFF) << 16)
                       | ((blob[3] & 0xFF) << 8)  | (blob[4] & 0xFF);
        byte[] out = new byte[uncompSize];
        int outPos = 0;
        // Bitstream starts at byte 5, LSB-first
        int bytePos = 5;
        int bitBuf = 0;
        int bitsLeft = 0;

        while (outPos < uncompSize && bytePos <= blob.length) {
            // Read flag bit
            if (readBit() == 0) {
                // Literal byte
                out[outPos++] = (byte) readBits(8);
            } else {
                // Match: decode length then offset
                int len = decodeLength();
                int offset = decodeOffset();
                int src = outPos - offset - len;
                for (int i = 0; i < len && outPos < uncompSize; i++) {
                    out[outPos++] = (src + i >= 0) ? out[src + i] : 0;
                }
            }
        }
        return out;
    }

    // Bit reading uses a closure-like approach with instance — but since this is static,
    // use a BitReader helper or inline. For simplicity, use a static inner class.
    // (Actual implementation will use a BitReader with state.)

    private CybikoDecompressor() {}
}
```

The actual implementation needs a `BitReader` inner class to track `bytePos`, `bitBuf`, `bitsLeft`. The length/offset decode trees from `docs/app-format.md`:

**Length tree:**
```
0 → 2
1,0 → 3
1,1,0 → 4
1,1,1,0,0 → 5
1,1,1,0,1 → 6
1,1,1,1,0,0 → 7
1,1,1,1,0,1 → 8
1,1,1,1,1 → read 8 bits + 1
```

**Offset tree:**
```
0 → read 6 bits (0-63)
1,0 → read 9 bits (0-511)
1,1,0 → read 12 bits (0-4095)
1,1,1 → read 13 bits + 4096
```

### Task 4: App Archive Parser — Implementation

**Step 1: Implement the parser**

```java
package com.github.daberkow.cybiko.manager.io;

import java.util.ArrayList;
import java.util.List;

/**
 * Parses Cybiko .app archive files ("Cy" magic).
 * Extracts embedded resource files (root.ico, main.e, etc.)
 * with automatic decompression.
 */
public final class CybikoAppParser {
    private record Entry(String name, int dataOffset, int dataSize) {}
    private final byte[] data;
    private final List<Entry> entries;

    public CybikoAppParser(byte[] appData) {
        if (appData.length < 6 || appData[0] != 'C' || appData[1] != 'y') {
            throw new IllegalArgumentException("Not a Cybiko .app archive (missing 'Cy' magic)");
        }
        this.data = appData;
        int count = readU16(2);
        entries = new ArrayList<>(count);
        for (int i = 0; i < count; i++) {
            int base = 6 + i * 10;
            int nameOff = readU16(base);
            int dataOff = readU32(base + 2);
            int dataSize = readU32(base + 6);
            // Read null-terminated name
            int end = nameOff;
            while (end < data.length && data[end] != 0) end++;
            String name = new String(data, nameOff, end - nameOff, java.nio.charset.StandardCharsets.US_ASCII);
            entries.add(new Entry(name, dataOff, dataSize));
        }
    }

    public List<String> listFiles() {
        return entries.stream().map(Entry::name).toList();
    }

    /** Extract and decompress a file by name. Returns null if not found. */
    public byte[] extractFile(String name) {
        for (var e : entries) {
            if (e.name().equals(name)) {
                byte[] blob = new byte[e.dataSize()];
                System.arraycopy(data, e.dataOffset(), blob, 0, e.dataSize());
                return CybikoDecompressor.decompress(blob);
            }
        }
        return null;
    }

    /** Get compressed blob without decompressing. Returns null if not found. */
    public byte[] extractRaw(String name) {
        for (var e : entries) {
            if (e.name().equals(name)) {
                byte[] blob = new byte[e.dataSize()];
                System.arraycopy(data, e.dataOffset(), blob, 0, e.dataSize());
                return blob;
            }
        }
        return null;
    }

    private int readU16(int off) {
        return ((data[off] & 0xFF) << 8) | (data[off + 1] & 0xFF);
    }

    private int readU32(int off) {
        return ((data[off] & 0xFF) << 24) | ((data[off+1] & 0xFF) << 16)
             | ((data[off+2] & 0xFF) << 8) | (data[off+3] & 0xFF);
    }
}
```

### Task 6: Icon Renderer — Implementation

**Files:**
- Create: `manager/src/main/java/com/github/daberkow/cybiko/manager/io/CybikoIconRenderer.java`

**Step 1: Implement the renderer**

Two layers: pure data conversion (testable without JavaFX) and JavaFX Image creation.

```java
package com.github.daberkow.cybiko.manager.io;

import javafx.scene.image.Image;
import javafx.scene.image.PixelFormat;
import javafx.scene.image.WritableImage;

/**
 * Converts Cybiko 2bpp grayscale icon data to JavaFX Images.
 */
public final class CybikoIconRenderer {

    private static final int[] PALETTE = {
        0xFFFFFFFF, // 0 = white
        0xFFAAAAAA, // 1 = light gray
        0xFF555555, // 2 = dark gray
        0xFF000000  // 3 = black
    };

    public record IconInfo(int width, int height) {}

    public static IconInfo parseHeader(byte[] icoData) {
        if (icoData == null || icoData.length < 8) return null;
        return new IconInfo(icoData[2] & 0xFF, icoData[3] & 0xFF);
    }

    /** Convert 2bpp pixel data to ARGB int array. Returns null on invalid input. */
    public static int[] toArgbPixels(byte[] icoData) {
        var info = parseHeader(icoData);
        if (info == null) return null;
        int w = info.width(), h = info.height();
        int[] pixels = new int[w * h];
        int bytesPerRow = (w + 3) / 4;
        int dataStart = 8;
        for (int y = 0; y < h; y++) {
            for (int x = 0; x < w; x++) {
                int byteIdx = dataStart + y * bytesPerRow + (x / 4);
                if (byteIdx >= icoData.length) break;
                int shift = 6 - 2 * (x % 4); // MSB = leftmost
                int val = (icoData[byteIdx] >> shift) & 0x03;
                pixels[y * w + x] = PALETTE[val];
            }
        }
        return pixels;
    }

    /** Create a JavaFX Image from icon data. Returns null on invalid input. */
    public static Image toImage(byte[] icoData) {
        var info = parseHeader(icoData);
        if (info == null) return null;
        int[] pixels = toArgbPixels(icoData);
        if (pixels == null) return null;
        WritableImage img = new WritableImage(info.width(), info.height());
        img.getPixelWriter().setPixels(0, 0, info.width(), info.height(),
            PixelFormat.getIntArgbInstance(), pixels, 0, info.width());
        return img;
    }

    private CybikoIconRenderer() {}
}
```
